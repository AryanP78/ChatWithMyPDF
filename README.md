# AskMyPDF

Chat with your PDFs — a Retrieval-Augmented Generation (RAG) app. Upload a PDF,
ask questions in natural language, and get answers grounded in the document,
with citations back to the source text.

**Stack:** React · Node/Express · PostgreSQL (pgvector) · Gemini (embeddings + LLM)

> Work in progress — building through a 10-phase roadmap.

## Structure
- `Backend/`  — Node/Express API (ingestion + query pipeline)
- `Frontend/` — React UI (Weekend 2)
